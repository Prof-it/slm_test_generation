 FOOTNOTES
==============================================================================================================
[1] COVERAGE METHODOLOGY: 'Gated Cov' (primary metric) measures line coverage restricted to assertion-passing tasks only, following Huang et al. (2025b) LCov@k. This is our primary coverage metric. Ungated (raw) coverage — which includes coverage from assertion-failing tests — was also computed but is not shown in the primary table; it is available in the evaluation JSONL files (field: coverage_all_tasks). Note: Wang et al. (2025a)'s 'Overall Line Coverage' (marked [a] in Table 1) applies a more lenient gating condition (Execution Correctness: test compiles and runs without crashing) rather than assertion passing; it is therefore not directly equivalent to our Gated Cov but is placed in the same column as the closest analogue.

[2] PYNGUIN TPS REPRESENTATION: Pynguin does not generate tokens; it uses evolutionary search (SBST/AST mutations). Pynguin is excluded from TPS trend plots. For cross-paradigm efficiency comparison, refer to the Wall-Clock Efficiency figure.

[3] STATISTICAL METHODOLOGY: All pairwise comparisons use Welch's t-test (unequal variances). P-values are Bonferroni-corrected for multiple comparisons. Effect sizes reported as Cohen's h (appropriate for proportions): |h|<0.2=negligible, 0.2-0.5=small, 0.5-0.8=medium, ≥0.8=large. 95% confidence intervals use t-distribution (N=1 runs, t-critical=inf, df=0).

[4] N=1 RUNS JUSTIFICATION: 1 independent runs per configuration balances statistical rigor with computational cost. With N=1: (1) 95% CIs use t-critical value of inf (df=0); (2) Bootstrap analysis confirms ranking stability across resampling. The variance convergence table demonstrates diminishing returns for additional runs.

[5] BOOTSTRAP STABILITY: Rankings assessed via 1000 bootstrap iterations resampling runs with replacement. 'Modal Rank' = most frequent rank position. 'Rank Stability' = percentage of iterations where configuration achieved its modal rank. High stability (>70%) indicates robust rankings.

[6] BEST CONFIGURATION SELECTION: For Tables 4-7, 'best configuration' for each model is defined as the configuration (prompt mode + temperature) with the highest mean Pass@1 across N=1 runs, excluding configurations with zero variance (which cannot be used in statistical tests). This reduces comparisons from all temperature variants to one representative per model.

EXPERIMENTAL SETUP (Real World Study):
• Hardware: vLLM, Single RTX 4090, FP16 precision (INT4 for quantized) 4096 max tokens.
• Dataset: 'Real World' - 299 Python functions from this repository's own codebase.
• Definitions:
  - Pass@1: % of tasks where the generated test compiles, runs, and all assertions pass (Chen et al. 2021).
  - Gated Cov: Line coverage on assertion-passing tasks only (Huang et al. 2025b, LCov@k).
  - Total Tokens: Average total tokens generated per run.
